01Conectar

En Integrations, junto a Shopify y WooCommerce. Al pegar la URL validamos antes de aceptarla: que responda, que sea XML, que traiga <item> y que apunte a un host público.

Validar antes de importar

Hoy no hay validación en el front: mandás cualquier cosa y el error vuelve del backend después. Los mensajes ya existen en base-api.

Host público, no interno

La URL la descarga una Cloud Function del lado del servidor, así que se rechazan localhost, IPs privadas y el metadata endpoint de GCP. Ya está implementado.

También acepta archivo

El endpoint toma un XML subido además de una URL. Un archivo suelto no se puede re-sincronizar, así que queda como import de un tiro, no como conexión.

El preview es gratis

Parsear el feed no escribe nada — los productos se publican al bus recién al confirmar. Podemos mostrar el resumen sin comprometer nada.

Por qué la cadencia se elige

Kondomeriet nos va a pedir respetar un límite de polling. Que sea un campo evita tocar código cuando lo pidan.

Cada hora cuesta casi nada

Mandamos If-None-Match y If-Modified-Since: si no cambió, el servidor responde 304 y no se descargan los 7 MB. Ya implementado.

Agrupar por categoría es lo único que escala

El feed trae g:product_type en el 100% de los items, así que el agrupado sale del dato, no de una heurística.

Destildar excluye, no borra

Una categoría sin publicar queda en draft y se puede publicar después. Los syncs siguientes la mantienen actualizada igual.

Esta pantalla vuelve

Cuando un sync trae productos nuevos, aparece otra vez con solo esos. Es el único momento en que se pide aprobación.
