## 2. Data de demo → staging

Para tener la demo accesible 24/7 en `api-staging.vio.live` sin depender del Mac local.

### Flow utilizado

1. **Angelo corre localmente:**
   ```bash
   yarn db:snapshot:push
   # → sube angelo-sepulveda-2026-06-03-1725.sql a saapivio/db-snapshots
   ```

2. **Restore en staging** (desde aquí, vía Container App Job):
   - Job `db-restore-staging` en `rg-api-vio-staging`
   - `DROP SCHEMA public CASCADE; CREATE SCHEMA public;` → restore limpio
   - SAS generado con `az storage blob generate-sas --account-key` (no user delegation)
   - Status: **Succeeded** ✅

3. **Deploy a staging:**
   ```bash
   gh workflow run deploy.yml -f environment=staging
   ```
