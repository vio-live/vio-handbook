# Session — 2026-06-08 — Klarna routes + doc audit + staging estable

## PR #38 — Klarna Payments routes para Web SDK

### Qué se hizo
Mergeado `feat(commerce): Klarna Payments session + order routes for the Web SDK` (#38, rama `fix/klarna-payments-routes`).

**Archivos cambiados:**
- `server/services/klarna.ts` — servicio nuevo, Basic-auth a Klarna API
- `server/routes.ts` — 2 rutas nuevas:
  - `POST /v2/commerce/klarna/sessions` → crea sesión Klarna, devuelve `clientToken` + `paymentMethodCategories`
  - `POST /v2/commerce/klarna/orders` → intercambia `authorization_token` por orden

**Por qué**: el Web SDK's inline Klarna widget necesitaba estas rutas en el backend. Sin ellas, las requests caían al catch-all de la SPA y devolvían HTML en lugar de JSON.
