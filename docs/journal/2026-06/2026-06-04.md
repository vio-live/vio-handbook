# Session — 2026-06-04 — Fix CORS x-api-key + Demo online

## Fix CORS: header x-api-key no permitido

### Síntoma
`vio-demo.vercel.app` llamaba a `https://api-staging.vio.live/v2/mobile/config` con el header `x-api-key` y el browser bloqueaba la request:

```
Access to fetch at 'https://api-staging.vio.live/v2/mobile/config' from origin
'https://vio-demo.vercel.app' has been blocked by CORS policy:
Request header field x-api-key is not allowed by Access-Control-Allow-Headers
in preflight response.
```

### Causa
`server/index.ts` tenía:
```ts
allowedHeaders: ['Content-Type', 'Authorization', 'Accept'],
```
El SDK de vio manda `x-api-key` en las requests — no estaba en la lista.

### Fix
```ts
allowedHeaders: ['Content-Type', 'Authorization', 'Accept', 'x-api-key'],
```

Commit `c514f09` en `tipiodevelopment/socket-server`, deplorado a staging y development (via push main).

### Verificación
```bash
curl -I -X OPTIONS "https://api-staging.vio.live/v2/mobile/config" \
  -H "Origin: https://vio-demo.vercel.app" \
  -H "Access-Control-Request-Headers: x-api-key"
# → access-control-allow-headers: Content-Type,Authorization,Accept,x-api-key ✅
```
