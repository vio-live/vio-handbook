# 2026-06-23 — Vio Sync (Shopify app)

Sesión sobre la app de Shopify reescrita (React Router). Detalle completo en
[`docs/handoff/shopify-sync.md`](../../handoff/shopify-sync.md).

## Lo que se hizo

- **Auth a Vio cambiado a API key** (antes era login Firebase email/password). La
  key va cruda en `Authorization`, guardada por-tienda en metafield `$app:vio`.
  Afuera Firebase / email-password / metafield-uid.
- **Pantalla principal = conexión** + **gating**: no se ven productos hasta conectar.
- **Disconnect** agregado (borra la key + avisa al backend).
- **App solo-exportar**: se sacó del scope import masivo, pagos y review (gratis,
  sin review). Terminología unificada a **"Export"** (Shopify → Vio).
- Aclarado el sentido del flujo: la app **exporta** productos de Shopify hacia Vio
  (el merchant es supplier). Las **órdenes** vuelven a Shopify vía webhook del backend.
- Levantado local OK con túnel named `shopify-dev.vio.live` (los quick tunnels de
  Shopify están rotos en esta red — 404 a todo).

Commits en `vio-shopify-sync` rama `rewrite/react-router-app`: `b1dfc52` (My products
+ rebrand + multi-entorno), `d0452d4` (API key + gating + disconnect + export).
